# Inspire Media – Eisteddfod Competition Toolkit

An online portal and venue tools for running dance eisteddfods and competitions.

- **Online portal** (in progress): organisers create events and programs, competitors enter and pay, upload music, and receive critiques.
- **Venue tools** (later): offline music playback for the sound desk and voice critique recording for the adjudicator.

See `TASKS.md` for progress, `DECISIONS.md` for what we decided and why, and `docs/requirements.md` for the full requirements.

## What works now (stage 1)

- Sign up, sign in and sign out.
- **Inspire admin** (platform admin): sees every organiser and creates new organisers.
- **Organisers**: create and edit events, add sessions and sections (with entry fees), import a program from CSV, edit items, scratch/reinstate, reorder, add late entries, add staff, publish a public event page, and download the program as CSV for the venue tools.
- **Public event page**: dates, venue, key dates and program overview, readable on a phone.
- Each organiser can only see and change their own competitions. This is enforced by the database itself and checked by automatic tests.

Coming soon (labelled in the app): online entry, shopping cart and Square payments, music upload, critiques.

## Running it on your own computer (Windows)

You need three free programs installed once:

1. **Node.js** (LTS version) from https://nodejs.org
2. **Git** from https://git-scm.com/download/win
3. **Docker Desktop** from https://www.docker.com/products/docker-desktop (runs the test database). Start it and leave it running.

Then open **PowerShell** and run these one at a time:

```powershell
git clone https://github.com/TheRickWard/Inspire-Media.git
cd Inspire-Media
npm install
copy .env.example .env.local
npm run db:start
npm run dev
```

The first `npm run db:start` downloads the database (a few GB) and can take 10 minutes or more. After that it starts in under a minute.

Open http://localhost:3000 in your browser. Stop the website with `Ctrl + C`, and the database with `npm run db:stop`.

```powershell

npm run lint
npm run build
```

## How it's built

- **Next.js + TypeScript + Tailwind** for the website (`src/`).
- **Supabase** for the database, logins and (later) file storage. Database structure and security rules are in `supabase/migrations/`. Sample data is `supabase/seed.sql`, generated by `scripts/make-sample-data.py`.
- Theme colours come from the Inspire Dance & Fitness logo (`brand/`, `src/app/globals.css`).
