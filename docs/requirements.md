Section1 - Pre Competition;



Event Organizer

* Create an event for a specific date, location
* Create the ability for competitors to enter a specified competition created by an event organizer
* Upload a dance program with the ability to amend the program online for (admin/event organizers user account only)
* The ability for competitors to create a user account which provides them with limited abilities (this access can be set by the competition organizer)
* The ability for the event organizer to add a late entry into a specified dance competition
* The ability to close or open event entry periods to a specific date
* Ability to download competition data which can be used for music playback and for voice critique recording
* Ability to download music which has been organized into a playlist specified by the event organizer and specific to the competition program flow and schedule
* Ability to take payment for each event entry. This event entry amount is determined by the event organizer
* Ability to give a receipt of payment for entered events.
* ability to only access the event associated to an admin login
* Ability to be able to create an event program which can be downloaded and published
* Ability to be able to create and download data reports
* Ability to be able to check competitors have uploaded their music and it is usable
* Ability to create user accounts and store user information



Event Competitors  

* Enter a specific event via event name, date, location, age, dance genre
* Upload their music with the ability to check and confirm the music is correct for the particular event via date, age and dance genre
* The ability to download a voice critique uploaded by the event convenor which has been provided in real time by a dance adjudicator. This can be synced to a folder available on this website portal
* Ability to make payment for each individual event entered, there should be a shopping cart function for multiple events entered





Section 2 - During Events

* Ability to be able to download music via event date for the specified event in an ordered playlist.
* Ability to be able to import and populate the event playlist in a purpose built onboard program designed for use with both Windows \& iOS
* Imported music to be populated in competition order for playback
* Ability to be able to play the play the competitor music from a user interface
* Ability to be able to record and upload adjudicator competition voice critiques via another User Interface/Program



Section 3 - Post Event



* Ability to be able to upload adjudicator voice critiques which can be synced to competitors folders for evaluation
* Ability to upload any missing voice critiques directly to a competitor or a competitor folder



Section 4 - Music Playback Software



* Ability to be able to import, populate music in an order specified via a date specified downloaded folder
* Ability to be able to play music via a simple play button next to each individual song. This track can be paused, stopped and scrolled back to start.
* Once a song starts no other song can be accidentally played
* Ability to be able to import late entry music via another source ie. Onboard Folder or USB Media
* Ability to be able to adjust output volume from withing the user interface
* Ability to be available for use on Windows or iOS



Section 5 - Voice Critiques Software

* Ability to be able to record competitor voice critiques 
* Ability for the voice critique record to sync to a competitor folder for later upload
* Ability to be able to select a microphone input source
* Ability to be able to select a competitor name which has been synced and identical to the competitor music
* Ability to be able to create an ongoing back to be run simultaneously in case there is a record issue
* ability to be able to see audio input levels in the user interface
* ability to be able to create a new user record if there is a late entry
* ability to be able to add competitor scores
